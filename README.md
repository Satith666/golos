# Golos

Изменение голоса для Windows 10 и 11. Меняет высоту и тембр голоса, добавляет эффекты (робот, рация, эхо и другие) и отправляет изменённый голос в Discord, CS2 и любые программы с микрофоном.

## Как поставить

1. Открой страницу [Releases](../../releases) и скачай `Golos.exe` из последней версии.
2. Запусти его. Если Windows покажет синее окно SmartScreen, нажми «Подробнее» и «Выполнить в любом случае».
3. На вкладке «Подключение» нажми **«Установить и настроить»**. Golos сам:
   - скачает VB-CABLE с официального сайта vb-audio.com и проверит подпись установщика;
   - установит его (Windows спросит разрешение администратора и подтверждение драйвера);
   - вернёт твои колонки или наушники, если Windows переключила звук на новый кабель;
   - сделает изменённый голос основным микрофоном Windows;
   - если нужна перезагрузка, после неё запустится сам и закончит настройку.

Discord и игры Steam с устройством ввода «По умолчанию» сразу слышат изменённый голос. При выходе из Golos основным снова становится твой обычный микрофон.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| Ctrl+Alt+V | включить или выключить изменение голоса |
| Ctrl+Alt+M | выключить микрофон |
| Ctrl+Alt+N | следующий голос |
| Ctrl+Alt+B | предыдущий голос |

## Если что-то не так

Если в окне появилась красная плашка, нажми в ней «Скопировать отчёт». Журнал лежит в `%APPDATA%\Golos\golos.log`.

## Как это устроено

- `dsp.py` — обработка голоса: сдвиг высоты с привязкой фаз к гармоникам, отдельный сдвиг тембра (формант), эффекты, шумовой гейт и шумодав.
- `audio_io.py` — звук через WASAPI (библиотека sounddevice/PortAudio). Все вызовы идут из одного потока, иначе Windows отказывается запускать звук.
- `cable.py` — установка и настройка VB-CABLE в один клик.
- `winsys.py` — устройства по умолчанию Windows, горячие клавиши, запуск с правами администратора.
- `app.py` и `ui.html` — программа и её окно (открывается через Edge в режиме приложения).

## Сборка

Каждое изменение в ветке `main` само собирается на серверах GitHub с Windows (`.github/workflows/build.yml`): тесты, сборка `Golos.exe`, самопроверка, проверки на настоящей Windows, выкладка в Releases.

Собрать у себя: запусти `BUILD.bat`, он поставит Python и библиотеки и соберёт `Golos.exe` рядом.

Тесты запускаются без Windows, на имитации звука и системы: `python tests/test_cable.py` и остальные файлы `tests/test_*.py`.
